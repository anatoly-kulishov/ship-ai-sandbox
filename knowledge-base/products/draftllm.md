# Draftllm

Draftllm собирает **черновик тренировки** из текстового brief.

## Вход
Краткое описание цели: «хочу накачать банки», «ноги и ягодицы», «грудные дома».

## Выход
JSON-план: список упражнений с id из каталога, подходы/повторы по шаблону. Несвободный текст.

## Ограничения
- Нельзя выдумывать упражнения вне whitelist.
- Если brief про зону (ноги), в план не попадают чужие зоны.
- Пустой пул после фильтра зоны → ошибка `invalid_plan`, не «весь каталог».

## Связь с Repdraft
В продукте экран `/ai`: brief → план → билдер. Lab больше не нужен как вход.
