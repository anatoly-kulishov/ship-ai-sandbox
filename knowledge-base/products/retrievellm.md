# Retrievellm

Retrievellm - слой **поиска** перед генерацией плана.

## Как работает
1. Каждое упражнение описывается текстом: название, зона, target, оборудование.
2. Текст → embedding (по умолчанию Ollama `nomic-embed-text`).
3. Brief → тот же embedding.
4. Cosine similarity → top-k кандидатов.
5. Regex-хинты сленга («банки» → руки) режут чужие зоны.

## Важно
Retrieve даёт **кандидатов**, не готовый план. План делает Draftllm по whitelist.

## Хранение
- Учебный минимум: JSON с векторами (урок 05).
- Docs-RAG: Chroma на диске (уроки 10–11).
