# Правило · Whitelist id

LLM **не** является источником правды по каталогу.

1. Модель может предложить только `id`, которые есть в переданном списке.
2. Код после ответа отбрасывает неизвестные id (`droppedUnknownIds`).
3. UI и база получают только проверенный план.

Если модель написала «жим супермена» без id - это баг промпта или схемы, не «фича».
