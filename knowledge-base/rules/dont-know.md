# Правило · «Не знаю»

Для RAG по документам (уроки 10–11):

1. Отвечай **только** по найденным чанкам.
2. Если в контексте нет ответа - скажи «не знаю по базе Fitllm», не выдумывай контракты и цифры.
3. В ответе указывай источник (`source`), когда это уместно.

Галлюцинация в knowledge-worker хуже короткого «не знаю».
