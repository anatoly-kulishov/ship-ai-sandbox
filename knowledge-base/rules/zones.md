# Правило · Зоны тела

Сленг brief нужно понимать однозначно:

| Сленг / фраза | Зона |
|---|---|
| банки, бицуха, руки | upper arms |
| грудные, pecs | chest |
| крылья, тяга | back |
| дельты, плечи | shoulders |
| ноги, ягодицы, бёдра | upper legs / lower legs |
| пресс | waist |
| предплечье | не плечи |

Zone brief: кандидаты и pad **только** из зоны. Иначе модель «дотягивает» чужими упражнениями ради красивого плана.
