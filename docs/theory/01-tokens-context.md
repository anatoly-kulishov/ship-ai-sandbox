# Теория · Tokens и context window

Источник идей: Ed Donner w3 (tokenizers) + guides. Практика: уроки 01, 06.

## Простыми словами
Модель не читает «слова». Текст режется на **токены** (куски: слово, часть слова, знак).  
«банки» ≈ 1–2 токена, длинный JSON - десятки.

**Context window** - сколько токенов модель видит за раз (system + история + твой ввод + место под ответ). Если не влезло - обрезают с начала или с конца: модель «забыла» правила.

## Зачем инженеру
- Дорогой API считают по токенам (вход + выход).
- В RAG нельзя пихать всю базу: режешь на чанки (урок 09).
- «Обрезало mid-sentence» = окно кончилось или `max_tokens` ответа маленький.

## Что запомнить
1. Токен ≠ слово.  
2. Окно = бюджет внимания.  
3. Сначала узкий retrieve, потом LLM - дешевле и точнее.
