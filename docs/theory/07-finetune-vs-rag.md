# Теория · Fine-tune vs RAG vs prompt

Источник идей: Ed Donner w6–7 (когда не учить модель зря). Практика: фаза H позже.

## Правило большого пальца

| Нужно | Что делать |
|---|---|
| Свежие факты / документы компании | **RAG** |
| Формат ответа, тон, JSON | **prompt + schema** |
| Узкий стиль/задача на своих примерах, факты стабильны | **LoRA** (light) |
| Новая «база знаний» каждый день | не fine-tune |

Fine-tune **не заменяет** retrieve: модель не «помнит» PDF, который ты не клал в датасет.

## LoRA / QLoRA (обзор)
Дообучаешь маленькие адаптеры, не все веса. На Middle+ рынке спрашивают «делал ли». У нас - после RAG и FastAPI (правило плана).

## Что запомнить
Сначала prompt → потом RAG → потом (редко) LoRA.
