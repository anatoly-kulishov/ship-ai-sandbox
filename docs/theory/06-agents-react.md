# Теория · Agents / ReAct

Источник идей: Ed Donner w2 tools + w8 agents. Практика: урок 02; полный agent - фаза E.

## Простыми словами
**Tool use** (урок 02): модель один раз выбирает функцию, код выполняет.  
**Agent**: цикл, пока задача не решена:

```text
мысль → выбрать tool → выполнить → наблюдение → снова мысль → …
```

Это **ReAct** (Reason + Act). Не путать с «пять фреймворков multi-agent».

## Когда нужен agent
- Несколько шагов и неизвестный порядок (поиск → уточнение → запись).  
- Когда одного structured call мало.

## Когда не нужен
- Один JSON на выходе (урок 01).  
- План из whitelist (урок 04).  
- Чистый RAG Q&A (уроки 10–11).

## Что запомнить
Сначала tools + RAG руками. Multi-agent и Modal - после, не вместо.
