# Теория · Chunking + overlap

Источник идей: Ed Donner w5 d2 (`RecursiveCharacterTextSplitter`). Практика: урок **09**.

## Зачем
Документ целиком не влезает в контекст и плохо ищется. Режем на **чанки** - куски текста с метаданными (`source`, тип).

## Overlap
Соседние чанки **перекрываются** (например 150–200 символов). Иначе предложение на границе разрезается, и поиск теряет смысл.

## RecursiveCharacter
Сначала пробуем резать по `\n\n`, потом `\n`, потом пробел, потом жёстко по длине. Так абзацы живут дольше, чем «тупые» каждые N символов.

Типичные стартовые значения (подкрутишь evals): `chunk_size≈800–1000`, `overlap≈150–200`.

## Что запомнить
Чанк без `source` бесполезен для citations. Overlap лечит границы, не «делает умнее».
