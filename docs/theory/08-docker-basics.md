# Теория · Docker (кратко)

Источник идей: Ed Donner guide 14. Практика: фаза F, урок 17 плана.

## Простыми словами
**Image** - снимок «ОС + зависимости + код».  
**Container** - запущенный image.  
**Compose** - несколько контейнеров одной командой (API + Postgres + vector).

Зачем LLM-gateway: у коллеги «у меня работает» совпадает с продом.

## Минимальная цель для рынка
`docker compose up` поднимает FastAPI + БД. Без Kubernetes на старте.

## Что запомнить
Сначала корректный API локально, потом упаковка. Docker не лечит плохой RAG.
