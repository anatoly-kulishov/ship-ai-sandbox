# Теория · Vector store (Chroma и дальше)

Источник идей: Ed Donner w5. Практика: урок 05 (JSON+cosine), **10** (Chroma), **11** (LangChain).

## Простыми словами
Эмбеддинг = вектор смысла.  
**Vector DB** хранит миллионы таких векторов и быстро отдаёт top-k похожих.

| Этап | У нас |
|---|---|
| руками cosine по JSON | урок 05 |
| Chroma persist | урок 10 |
| то же через LangChain | урок 11 |
| Qdrant / pgvector | план D12, когда вырастем |

## Зачем не сразу Qdrant
На учёбе важна механика. Chroma = файл на диске, без кластера. Для Repdraft каталога хватает JSON; для docs-RAG нужен store.
