# Теория · System / user и temperature

Источник идей: Ed Donner w1 + w5 (справка про temperature). Практика: урок 01.

## System vs user
- **System** - кто ты и какие правила (контракт сервиса).  
- **User** - конкретный запрос пользователя.  
Не мешай: правила в system, данные в user.

## Temperature
Не «креативность». Это насколько часто брать **не** самый вероятный следующий токен.

| Значение | Когда |
|---|---|
| `0` | классификация, JSON, whitelist, RAG-ответ по фактам |
| `0.3–0.7` | обычный текст |
| выше | эксперименты; в продукте редко нужно |

`temperature=0` не гарантирует бит-в-бит одинаковый ответ на всех железах - но для сортировщика этого достаточно.

## Паттерны (узнавать по имени)
- **Few-shot** - 1–3 примера в промпте (как в brochure Ed: one-shot JSON).  
- **CoT** - «думай по шагам» (осторожно: длиннее и дороже).  
- **ReAct** - мысль → tool → наблюдение (см. [06-agents](./06-agents-react.md)).

## Что запомнить
Правила в system, факты в контексте (RAG), проверка схемой в коде.
