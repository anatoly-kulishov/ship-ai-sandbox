# 05 · RAG по каталогу зала

[Уроки](../README.md#уроки) · [← 04](./04-gym-plan.md) · [06 →](./06-gguf.md)

LEARNING_PLAN: фаза D, урок 11. В sandbox папка `05-rag/`.

## Зачем
В урок 04 весь каталог пихается в промпт. Так нельзя, когда упражнений тысячи: дорого, легко промахнуться мимо зоны. Сначала **ищем** похожие, потом генерируем план из короткого списка.

## Простыми словами
**RAG** = retrieval-augmented generation: «сначала найди куски, потом отвечай». Здесь поколение ещё нет: только поиск.

**Эмбеддинг** - список чисел (вектор), который кодирует смысл текста. «Банки» и «сгибание на бицепс» окажутся рядом, хотя буквы разные.

**Косинус** - насколько два вектора смотрят в одну сторону (от -1 до 1, для похожих текстов ближе к 1).

Векторную базу (Qdrant) не ставим: векторы лежат в JSON, косинус считаем циклом в Python. Так видно механику.

Сленг ловим ещё regex: «банки» → зона `upper arms`, и косинус режем по этой зоне, чтобы ноги не перебили топ.

## Как сделали
| Файл | Роль |
|---|---|
| `05-rag/catalog.fixture.json` | те же упражнения, что в 04 |
| `05-rag/embeddings.py` | embed, cosine, hints, retrieve |
| `05-rag/embeddings.fixture.json` | сохранённый индекс (id + vec) |
| `05-rag/check.py` | `build` / `embed` / `retrieve` |
| `05-rag/app.py` | brief + top-k таблица |

Эмбеддинги по умолчанию: Ollama `nomic-embed-text`. У GigaChat на тарифе PERS `/embeddings` часто отвечает 402.

В Repdraft индекс: `static/data/exercises.embeddings.json`. Пока stub пустой - в проде работает regex. Hybrid (cosine ∪ regex) включается после `npm run build:embeddings`.

## Как работает
1. `build`: каждое упражнение → текст «название | зона | target | оборудование» → вектор → файл.
2. Brief («хочу накачать банки») → подсказки зон regex → тот же embed.
3. Считаем cosine brief ↔ каждое упражнение.
4. Если есть хинт зоны - чужие `body_part` выкидываем.
5. Сортируем, берём top-k. Это **кандидаты**, не план.

План = retrieve (этот урок) + LLM whitelist (урок 04). Так устроен `/ai` в Repdraft.

## Что потрогать
```bash
npm run ollama:start
ollama pull nomic-embed-text
python 05-rag/check.py build
python 05-rag/check.py retrieve "хочу накачать банки"
```
Hub → **05 RAG** или `npm run 05`.

## Готово, когда
- [ ] В `embeddings.fixture.json` есть vec на каждый id
- [ ] «Банки» / «руки» тянут верх рук, а не ноги
- [ ] Понимаешь: поиск ≠ генерация плана

Сначала узкий список из справочника, потом LLM. Иначе модель фантазирует упражнения.
