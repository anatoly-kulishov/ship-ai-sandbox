# 04 · Gym plan (план из каталога)

[Уроки](../README.md#уроки) · [← 03](./03-ollama.md) · [05 →](./05-rag.md)

## Зачем
Срез продукта Repdraft: человек пишет brief («грудь и трицепс, 45 минут, штанга»), приложение собирает план. Модель не имеет права выдумать упражнение, которого нет в зале.

## Простыми словами
**Whitelist** - белый список id. Модель предлагает `exerciseId`, код выкидывает всё, чего нет в `catalog.fixture.json`. Это граница доверия: галлюцинация «superSquat9000» не попадает в билдер.

Дальше код добивает план до 5–8 упражнений, если модель вернула слишком мало известных id.

GigaChat отдаёт план через function calling (`submit_plan`). Ollama - через JSON в тексте (`json_object`). Разбор разный, схема Pydantic одна.

## Как сделали
| Файл | Роль |
|---|---|
| `04-gym-plan/catalog.fixture.json` | урезанный каталог упражнений |
| `04-gym-plan/generate.py` | промпт, вызов LLM, whitelist, pad |
| `04-gym-plan/check.py` | CLI: brief → JSON плана |
| `04-gym-plan/app.py` | brief текстом или голосом |

В Repdraft тот же навык живёт на `/ai`: generate + whitelist + (позже) retrieve.

## Как работает
1. Грузим каталог, собираем множество разрешённых id.
2. Кладём каталог **в system prompt** списком строк `id | название | зона | оборудование`.
3. Brief пользователя - в user message.
4. Ответ парсим в `WorkoutPlanOut` (имя, 1–8 упражнений, диапазоны sets/reps/rest).
5. `filter_known_ids` - выкинуть неизвестные. Если не осталось ни одного - ошибка, не «подставь весь зал».
6. `pad_to_min` - добрать с начала каталога до минимума 5.
7. Наружу: план + сколько id отбросили (`droppedUnknownIds`).

Модель предлагает. Код - кассир на входе в зал.

## Что потрогать
```bash
python 04-gym-plan/check.py "грудь и трицепс, 45 минут, штанга"
```
Hub → **04 Gym Plan** или `npm run 04`. Сравни тот же brief на GigaChat и Ollama (`npm run provider:...`).

## Готово, когда
- [ ] В плане только id из fixture
- [ ] Тот же brief проходит на обоих провайдерах
- [ ] Понимаешь: фильтр id - не «промпт попросил вежливо», а код

## Что запомнить
Свободный текст модели не является источником истины для id сущностей. Справочник - твой.
